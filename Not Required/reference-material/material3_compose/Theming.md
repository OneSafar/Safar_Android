# Theming with Material 3 in Jetpack Compose

Material 3 uses a **theme** that consists of three subsystems: **colour scheme**, **typography** and **shapes**.  Compose exposes these through the `MaterialTheme` composable, which wraps your app’s UI and injects the theme values into the hierarchy.  This file explains how to set up the Material 3 dependency, define your own colours, fonts and shapes and support dynamic colour and dark mode.

## 1. Add the Material 3 dependency

To start using Material 3, add the `androidx.compose.material3:material3` library to your project.  The Android Developers guide states that you must declare the dependency in your `build.gradle` file before you can access M3 components【641042291835853†L866-L873】:

```gradle
dependencies {
    implementation "androidx.compose.material3:material3:<latest-version>"
}
```

Replace `<latest-version>` with the current release of the `material3` library (see [Compose release notes](https://developer.android.com/jetpack/compose/releases)).  If you use any APIs marked with `@ExperimentalMaterial3Api`, annotate the relevant functions or files with `@OptIn(ExperimentalMaterial3Api::class)`【641042291835853†L876-L884】.

## 2. MaterialTheme structure

Wrap your app’s content in `MaterialTheme` and provide values for `colorScheme`, `typography` and `shapes`.  The M3 theme encapsulates colours, font styles and container shapes.  When you modify one of these subsystems, your changes automatically propagate through all Material 3 components【641042291835853†L889-L909】.

```kotlin
@Composable
fun MyApp(content: @Composable () -> Unit) {
    MaterialTheme(
        colorScheme = myLightColorScheme,
        typography = myTypography,
        shapes = myShapes
    ) {
        content()
    }
}
```

### Colour scheme

A Material 3 colour scheme is built from **five key colours** (primary, secondary, tertiary, neutral and error).  Each key colour generates a tonal palette of 13 tones which are mapped to roles such as `primaryContainer` and `onPrimary`【641042291835853†L915-L920】.  The Android documentation suggests generating a scheme using the **Material Theme Builder** tool; this tool exports `Color.kt` and `Theme.kt` files that define light and dark palettes【641042291835853†L929-L977】.  An excerpt of a generated light palette looks like this【641042291835853†L934-L947】:

```kotlin
// Color.kt – generated by Material Theme Builder
val md_theme_light_primary = Color(0xFF476810)
val md_theme_light_onPrimary = Color(0xFFFFFFFF)
val md_theme_light_primaryContainer = Color(0xFFC7F089)
val md_theme_light_onPrimaryContainer = Color(0xFF132400)
// ...

// Theme.kt – choose between light and dark palettes
private val LightColorScheme = lightColorScheme(
    primary = md_theme_light_primary,
    onPrimary = md_theme_light_onPrimary,
    primaryContainer = md_theme_light_primaryContainer,
    onPrimaryContainer = md_theme_light_onPrimaryContainer,
    // ... include secondary, tertiary, error and neutral roles
)

private val DarkColorScheme = darkColorScheme(
    primary = md_theme_dark_primary,
    onPrimary = md_theme_dark_onPrimary,
    primaryContainer = md_theme_dark_primaryContainer,
    onPrimaryContainer = md_theme_dark_onPrimaryContainer,
    // ... other roles
)

@Composable
fun MyTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    content: @Composable () -> Unit
) {
    val colors = if (darkTheme) DarkColorScheme else LightColorScheme
    MaterialTheme(colorScheme = colors, content = content)
}
```

#### Dynamic colour

Dynamic colour uses the user’s wallpaper as a seed to generate a colour palette.  Dynamic colour is available on Android 12 and above; Compose exposes `dynamicDarkColorScheme(context)` and `dynamicLightColorScheme(context)` to obtain dynamic palettes【641042291835853†L989-L1015】.  Fallback to your custom palette when dynamic colour isn’t supported:

```kotlin
@Composable
fun MyTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    dynamicColor: Boolean = true,
    content: @Composable () -> Unit
) {
    val context = LocalContext.current
    val colorScheme = when {
        dynamicColor && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S && darkTheme ->
            dynamicDarkColorScheme(context)
        dynamicColor && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S && !darkTheme ->
            dynamicLightColorScheme(context)
        darkTheme -> DarkColorScheme
        else -> LightColorScheme
    }
    MaterialTheme(colorScheme = colorScheme, content = content)
}
```

### Typography

Material 3 defines a simplified **type scale**.  The type styles are grouped into **display**, **headline**, **title**, **body** and **label**, with large, medium and small sizes in each group【641042291835853†L1076-L1099】.  Compose provides a `Typography` class that lets you override individual styles.  The example below defines a custom `titleLarge` and `titleMedium` and passes the result to `MaterialTheme`【641042291835853†L1109-L1158】:

```kotlin
val myTypography = Typography(
    titleLarge = TextStyle(
        fontWeight = FontWeight.SemiBold,
        fontSize = 22.sp,
        lineHeight = 28.sp,
        letterSpacing = 0.sp
    ),
    titleMedium = TextStyle(
        fontWeight = FontWeight.SemiBold,
        fontSize = 16.sp,
        lineHeight = 24.sp,
        letterSpacing = 0.15.sp
    ),
    // define other styles only if you need to override defaults
)

@Composable
fun MyApp() {
    MaterialTheme(typography = myTypography) {
        // Content that uses MaterialTheme.typography.titleLarge etc.
    }
}
```

To access a text style, refer to `MaterialTheme.typography.bodyLarge`, `MaterialTheme.typography.titleMedium` and so on【641042291835853†L1164-L1174】.

### Shapes

Shapes control the roundedness of component containers.  Material 3 introduces an expanded **shape scale** with five sizes: **extra small, small, medium, large and extra large**【641042291835853†L1182-L1202】.  Compose exposes a `Shapes` class where you can override each size to specify a `RoundedCornerShape`.  For example【641042291835853†L1190-L1212】:

```kotlin
val myShapes = Shapes(
    extraSmall = RoundedCornerShape(4.dp),
    small = RoundedCornerShape(8.dp),
    medium = RoundedCornerShape(12.dp),
    large = RoundedCornerShape(16.dp),
    extraLarge = RoundedCornerShape(24.dp)
)

@Composable
fun MyApp() {
    MaterialTheme(shapes = myShapes) {
        // Components will inherit these corner sizes unless overridden
    }
}
```

You can also use `RectangleShape` (no rounded corners) or `CircleShape` for circular surfaces【641042291835853†L1247-L1253】.  To apply a shape on a per‑component basis, pass a `shape` parameter to the component (e.g., `Card(shape = MaterialTheme.shapes.medium)`【641042291835853†L1231-L1239】).

## 3. Emphasis and elevation

Material 3 emphasises content through combinations of surfaces and on‑colour pairs.  Use surface, surface‑variant and background colours with their corresponding `onSurface` variants to achieve different emphasis levels【641042291835853†L1265-L1275】.  Font weight can also convey emphasis; for example, use `FontWeight.Bold` for important text【641042291835853†L1278-L1287】.

Elevation in Material 3 uses **tonal colour overlays** in addition to shadows【641042291835853†L1293-L1316】.  The `Surface` composable accepts `tonalElevation` and `shadowElevation` parameters that you can adjust to differentiate surfaces:

```kotlin
Surface(
    tonalElevation = 4.dp,
    shadowElevation = 2.dp
) {
    // Elevated content
}
```

Use tonal elevation primarily for dark themes, where surfaces need to be distinguished through colour, and combine it with `shadowElevation` for lighter themes.
