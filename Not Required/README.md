# Preserved non-runtime material

This directory contains files that are not required to build the active
Android application but are kept for reference instead of being deleted.

- `reference-material/` — downloaded Compose/Material examples and skills.
- `legacy-output/` — output from the older singular `Output` location.
- `dev-scratch/` — scratch diffs and test files.
- `downloads/` — downloaded archives.
- `system-files/` — operating-system metadata.
