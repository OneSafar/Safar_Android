# Repository organization

## Active Android project

- `app/` — Android application module and all runtime source/resources.
- `gradle/`, `gradlew`, `gradlew.bat` — Gradle wrapper and version catalog.
- Root Gradle files — project configuration required by Gradle and Android
  Studio.
- `Outputs/` — deliberately retained APK/AAB release artifacts.
- `SAFAR_release_signing_bundle/` — local release-signing setup used by the
  release script.

## Supporting material

- `Docs/` — specifications, guides, audits, plans, and design references.
- `scripts/design-tools/` — one-off asset transformation utilities.
- `RLEEASE Asset/` — Play Store/release artwork retained at its existing path.
- `stitch-export/` — retained design export.
- `Not Required/` — old output, scratch files, downloaded references, and
  system metadata. These files are preserved, not deleted.

Generated Gradle, Kotlin, IDE, and module build directories remain ignored and
can be regenerated by the normal build.
