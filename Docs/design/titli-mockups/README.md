# Titli tutorial menu design concepts

Generated with the built-in image-generation tool as visual mockups, not app screenshots or final production artwork. No app code was changed. Layout, icon rendering, gradients and text sizing are concept-level; native implementation must retain real accessible controls and Titli's black wings with pink boundary/spots.

1. `01-playful-stickers.png`: warm ivory, plum action button, coral/lilac lesson accents, a bold sticker cluster with a yellow sun, coral hourglass tile, lavender arch and green leaves.
2. `02-bold-color-blocks.png`: charcoal, pale text, coral action button, compact colorful icon tiles and an oversized geometric arrangement in cobalt, coral, yellow, lavender and emerald.
3. `03-soft-geometry.png`: pale blush, plum text/button, white rounded rows and an asymmetrical arrangement of coral, butter yellow, sage and lilac shapes.

The third concept is the closest match to SAFAR's existing warm, rounded visual language. The second is a stronger geometric direction. All three can be adapted into both light and dark palettes.

## Prompt set

Shared brief: create a polished, flat, front-facing portrait Android UI mockup of SAFAR's Ekagra lesson-selection menu. Preserve Learn Ekagra, the practice-data caption, the focus-ready heading, four existing lesson names, completion state, Help/Close controls and OK action. Keep expressive decorative artwork below controls in the lower 35% of the screen. Use readable Android typography and realistic touch targets. Avoid faint mandala/orbit line art, photographed phones, browser chrome, external-site branding and unrelated text. Preserve Titli's black wings and pink glowing edges/spots.

Concept 1 brief: playful sticker aesthetic; ivory canvas, black type, plum OK button, white/peach/lavender lesson surfaces. Three overlapping oversized stickers: a yellow scalloped friendly sun, coral diamond with hourglass pictogram, lavender arch with black sparkle, plus green leaf and butterfly accents.

Concept 2 brief: bold geometric dark mode; charcoal canvas, light text, coral OK button, colored icon tiles. Lower composition uses a cobalt semicircle, butter-yellow stepped block, coral quarter-circle, lavender squircle/circle cutout and emerald rectangle with pink dot. Flat, high-contrast, balanced poster composition without faces or cyberpunk styling.

Concept 3 brief: calm soft geometry; blush-white canvas, dark aubergine text, white rows, plum OK button. Lower composition uses a large coral wavy half-disc, yellow arch, lilac squircle, sage two-lobed leaf, plum sparkle and pink circle. Asymmetric solid shapes, warmer and calmer than the other concepts.

## Selected concept

The user selected **03 Soft Geometry**. Its native implementation is documented in `Docs/tutorials/titli-soft-geometry-2026-10-20.md`. The PNG remains a design reference; the app uses Compose components and vector paths rather than embedding the mockup image.
