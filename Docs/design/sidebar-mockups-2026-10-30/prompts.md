# Sidebar mockups — 30 October 2026

Built-in image generation. Three proposed alternatives, not screenshots of implemented code. No app code changes.

## 01-soft-minimal

Use case: ui-mockup.
Create a single high fidelity portrait UI mockup of SAFAR Android app with its redesigned sidebar OPEN, 1024x1920. It should be a credible production UI specification: flat edge-to-edge image, no phone frame, no emulator title, no fake OS status/navigation bars, no presentation captions outside the UI. Sidebar occupies 88% of screen width and full height, gently rounded right corners; remaining 12% is dimmed blush underlying app with neutral white card fragments, no readable background text. This is a SIDEBAR redesign, not a landing page.
Reference image 1 (YouTube Focus) is the approved visual style: blush, plum, geometric accent and typography. Reference image 2 (Premium) supplies membership styling. Do not copy the YouTube screen content or Premium purchase UI.
App color tokens: blush canvas #FFF5F0, paper #FFFDFC, ink #39132E, muted text #75616F, action plum #542347, peach #FFCBBE, lilac #CDBBE9, sage #8EAD7C, mint #C9EFE0. Poppins-like upright sans serif. Premium quality through precise alignment, restrained contrast, comfortable touch targets, simple consistent 22dp line icons and generous but purposeful spacing. No gold, neon, glass, 3D, gradients, heavy shadows, cartoon illustration or oversized decorative art. Small original black and pink butterfly may accompany SAFAR wordmark. Use only supplied exact copy. Every item must be readable and fit without clipping.
INFORMATION ARCHITECTURE common to all variants:
A small top row: 'SAFAR' and an X close control.
A clearly tappable account header: circular avatar with initial 'D', name 'developer', mint status pill 'Premium active', small text 'Profile & membership', trailing chevron. This opens profile and membership. No invented email or metrics.
Exactly FIVE primary navigation rows in this order, with icon and these exact title/subtitle pairs:
'Home' / 'Your day at a glance'
'Study' / 'Planner, focus tools & resources'
'Wellbeing' / 'Nishtha, Dhyan & live sessions'
'Community' / 'Mehfil, circles & leaderboard'
'Progress' / 'Analytics, streaks & reports'
Study is the only selected destination. Selection must be obvious and not rely only on text color. These rows OPEN hub screens; there are NO expansion arrows or accordions and NO child-feature lists inside the drawer. Subtitles preview contents, not additional controls.
Below main navigation, smaller secondary section with tappable rows: gear icon 'Settings' and question-circle 'Help & support'. At very bottom a discreet separated row 'Admin tools' with shield icon, because this preview is an admin account. Settings contains language and appearance; do not put a large language selector or theme switch on the sidebar. Do not add a separate Premium sales card, duplicate profile item, search, feature counts, charts, fake notifications, new slogans or extra navigation entries.
All icons, titles, captions and touch targets use consistent left alignment and readable hierarchy. Total screen should feel calm but not mostly empty.

VARIANT A — SOFT MINIMAL. Entire drawer is warm blush. Account header is one modest white rounded card below SAFAR bar. Main navigation is a clean unboxed vertical list, with generous 74dp-like row height and icon left, label plus smaller caption right. Study has a pale lilac rounded pill spanning row width with a narrow plum vertical accent and bold plum icon/text. Inactive rows remain on blush. Thin divider separates secondary settings/help rows near lower area. Admin tools subtle footer. Use small peach circular avatar, restrained tiny mint badge. Quietest and most minimal design; no decorative artwork.
