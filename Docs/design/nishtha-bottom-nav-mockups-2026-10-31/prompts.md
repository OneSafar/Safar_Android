# Nishtha bottom navigation concepts

Built-in image generation; three alternative designs of the same Goals-selected state. App code unchanged.

## 01-soft-pill

Use case: ui-mockup. Create ONE high-fidelity close-up mockup of the BOTTOM portion of Nishtha Android app, landscape image approximately 1536x1024, a zoomed crop of one phone app footer, NOT a full phone, no device frame, no emulator chrome, no fake status bar, no presentation captions. The attached current navigation crop is a reference for the four destinations and order ONLY, not its plain styling. Top 55 percent of image shows a quiet warm blush #FFF5F0 screen section with a cropped WHITE rounded card, small label 'Today Pulse' and '0 completed goals' in muted sage. Keep this surrounding content IDENTICAL between variants; redesign ONLY navigation below it. Remaining lower 45 percent features the proposed bottom navigation with comfortable Android safe area below it. No Android gesture line drawing required, show clear safe-area breathing room. Native Compose-feasible, premium polished minimal, flat vector icons, no raster artwork inside icons, no glossy/glass/3D or gradients. Warm paper #FFFDFC surfaces, dark plum #39132E ink, primary plum #542347, muted #75616F, pale lilac #EDE0F4, mint #C9EFE0, peach #FFCBBE. Upright Poppins-like typography. EXACTLY FOUR equal-width destinations in this order, all four labels always visible: 'Check-In' with simple outlined heart, 'Journal' with outlined journal/book, 'Goals' with flag, 'Streaks' with flame. GOALS is selected, the other three are inactive. Consistent icon size and baseline, labels aligned, minimum 48dp-equivalent touch targets. The selected state must use shape/fill and weight, not color alone. Do NOT add a raised central action, extra tabs, badges, checkmarks on nav, extra headings or any feature content. Reference colors need to match SAFAR Profile/Premium/Home palette: blush plum lilac mint; no old teal-only nav. Show exactly one footer design per image.

VARIANT 1: SOFT PILL INDICATOR. Attached full-width paper bottom navigation surface with gently rounded upper corners (24dp-equivalent) and a fine warm border, no heavy shadow. Four evenly spaced columns: 24dp icons above 12sp labels. Selected Goals has a wide pale lilac pill BEHIND ONLY THE ICON, filled plum flag centered within, with bold plum Goals label below on the base surface. Inactive icons and labels muted plum, no icon backgrounds. Airy restrained 76dp-equivalent bar plus safe area. Calmest and clearest native style.
