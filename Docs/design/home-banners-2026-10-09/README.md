# SAFAR home banner mockups

Ten original PNG mockups, each 2172 × 724 pixels (3:1): five YouTube Focus and five Habit Tracker concepts.

Open `index.html` to compare them, filter by feature, preview at 360px, and download individual PNGs. Files are visual mockups; button areas are part of each image.

Generated using the built-in image_gen tool. The complete final prompt set is in `prompts.json`. Original outputs are retained; `assets.json` maps the workspace images to their originals.
