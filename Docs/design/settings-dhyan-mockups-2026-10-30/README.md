# Settings and Dhyan mockups

Six ImageGen visual concepts for selection. No application code changes.

Settings: 01 Soft groups; 02 Plum account header; 03 Quiet list.
Dhyan: 01 Lavender breathing stage; 02 Open calm; 03 Plum session console.

Style reference: existing SAFAR soft-geometry premium mockup, with ivory/plum/peach/lavender colors shared by Profile, Sidebar and Mehfil.
Feature scope checked against SettingsScreen.kt, SettingsUiState.kt, DhyanScreen.kt and DhyanTopNavigation.kt.
Settings previews show sample preferences, not actual account state. Lower legal/account sections continue below the fold; admin controls remain conditional in implementation.
Dhyan shows a sample ready-state Box breathing session with a 5-minute duration, existing reset/play/mute, duration, technique and audio controls. Ring and slider positions are illustrative, not validated runtime states.

Final selected implementation must retain current behavior, access checks, reduced-motion support, font scaling, scrolling, keyboard interaction and safe insets. Images are visual targets, not screenshots of implemented screens.
