# Habit Tracker — YOUR DAY. IN SYNC.
15-second kinetic promo for students, using the supplied Habit Tracker and Timetable screens.

- Finished film: renders/HABIT_TRACKER_PROMO.mp4
- 1920×1080, 30 fps, H.264 yuv420p, CRF16, stereo AAC.
- Six scenes: big goals / make time / link a habit / track progress / study–move–reset / your day in sync.
- Original synthesized 144 BPM music and SFX. No voice-over.

## Re-render
Run `node render.mjs`. This uses pinned HyperFrames 0.9.5 and verifies the final codec, pixel format, and duration. Node 22+ is required; the script can use this machine's installed Homebrew Node 22 automatically. Its QA score gate requires every final category to be at least 8.

## Edit
- index.html: composition hosts and score.
- compositions/: six editable scene clips.
- lib/motion.js: deterministic time-based artwork, screenshot placement, choreography and text.
- DESIGN.md / SPEC.md: creative and render contracts.
- assets/screens/: supplied screenshot and original screen crops.
- assets/crop-manifest.json: exact product-detail source coordinates.
- synthesize.py: original score and normalization.
- beats.json: note-start grid and measured PCM beat onsets.
- qa/: beat sheets, motion strips, verification reports, and final decoded-frame review.
- REVIEW.md: scored iterations, fixes, and limits of what was checked.

Every frame is generated by window.seek(t). Local assets initialize once; frames carry no animation state. No authored CSS transitions, timers, animation-frame clock, or unseeded noise.
